An API reference page whose description opens with the lead-in to a list ("Supports two modes:") no longer ends its meta description in a dangling `:` or `:.`. The list's items now follow the lead-in ("Supports two modes: Explicit IDs; Select all."), on operation and overview pages and with `seoDescriptionSuffix` off. A lead-in to anything else, such as a code block, closes with a period, and a colon that belongs to the text, like inline code ending in `tenant:`, stays. Operation summaries on the agent surfaces close the same way.
