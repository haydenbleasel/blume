## Install the client

```bash
npm install @acme/commerce
```

## Create an order

```js
import { Acme } from "@acme/commerce";

const acme = new Acme({ token: process.env.ACME_TOKEN });
await acme.orders.create({ items: [{ sku: "tee", quantity: 1 }] });
```

## Install the client

```bash
pip install acme-commerce
```

## Create an order

```python
from acme import Acme

acme = Acme(token=os.environ["ACME_TOKEN"])
acme.orders.create(items=[{"sku": "tee", "quantity": 1}])
```
