This page exists **only in the current docs** — there is no `v1.0` equivalent. It exercises the versioning edges:

- **Switcher fallback** — switch to **v1.0** while on this page: with `switcher.redirect: "same-page"` (the default) there is no equivalent page, so you land on the v1.0 root instead.
- **Version-scoped search** — press <kbd>⌘K</kbd> (<kbd>Ctrl+K</kbd> on Windows and Linux) and search for "sparkle unicorn payload": this page only matches when viewing the current docs, or with the all-versions toggle on.
- **Old-version banner** — every `v1.0` page shows the "you're viewing an old version" notice linking back to the latest docs.
- **Canonical URLs** — `v1.0` pages that still exist in the current docs point their canonical at the live page (`canonical: "latest"`, the default).

The frozen tree was cut with:

```bash
blume version v1.0
```

which copied the content root into `content/v1.0/`, rewrote root-absolute links inside the copy to stay within the snapshot, and registered the id in `blume.config.ts`.
