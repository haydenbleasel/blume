## What's enabled

- **Native OpenAPI reference** at [/api](/api), with expanded schema rows and code samples.
- **Native AsyncAPI reference** at [/events](/events) — Kafka, WebSocket, and MQTT operations from `specs/asyncapi.yaml`.
- **Search** (Orama) with curated popular links — press <kbd>⌘K</kbd> (<kbd>Ctrl+K</kbd> on Windows and Linux).
- **Ask AI**, **MCP server** at `/mcp`, `llms.txt`, and WebMCP.
- **i18n** with English and German (fallback to English).
- **Export** to PDF and EPUB from the page actions menu.
- **RSS** for the blog and changelog, OG images, sitemap, structured data.
- **Last modified** stamps from git, feedback widget, dismissible banner.

:::note
The changelog tab is materialized from the `haydenbleasel/blume` GitHub releases at startup, so it needs network access (and may rate-limit without a `GITHUB_TOKEN`).
:::
