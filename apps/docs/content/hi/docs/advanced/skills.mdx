Blume [एजेंट स्किल्स](https://docs.claude.com/en/docs/claude-code/skills) के साथ आता है — ऐसे प्लेबुक जो किसी कोडिंग एजेंट (Claude Code, Codex, Cursor) को यह सिखाते हैं कि Blume से जुड़ा काम कैसे किया जाए, बिना आपके समझाए। ये GitHub पर रिपॉज़िटरी के `skills/` फ़ोल्डर में रहते हैं और इंस्टॉल किए गए पैकेज में `skills/` के अंतर्गत बंडल किए जाते हैं, इसलिए किसी भी एजेंट को सीधे `SKILL.md` की ओर इंगित किया जा सकता है।

## Blume

मुख्य स्किल। यह एजेंट को सिखाती है कि Blume क्या है और किसी साइट को कैसे स्कैफ़ोल्ड करना, लिखना और कॉन्फ़िगर करना है — फ़ाइलसिस्टम से व्युत्पन्न नेविगेशन, कॉन्फ़िग स्कीमा, कंटेंट कंपोनेंट्स — और इसे इंस्टॉल किए गए पैकेज में बंडल किए गए पूरे डॉक्स की ओर इंगित करती है (`blume` के भीतर की `docs/` डायरेक्टरी, जो वहीं से रिज़ॉल्व होती है जहाँ आपका पैकेज मैनेजर इसे इंस्टॉल करता है — pnpm मोनोरेपो में वह डिपेंडिंग वर्कस्पेस का `node_modules` होता है, रिपॉज़िटरी की रूट नहीं)। इसे किसी भी ऐसे प्रोजेक्ट में इंस्टॉल करें जहाँ कोई एजेंट आपके डॉक्स बनाने में मदद करता है:

```bash
npx skills add haydenbleasel/blume
```

## माइग्रेशन [#migration]

`blume-migrate` किसी मौजूदा डॉक्स साइट को Blume पर ले जाता है: Mintlify, Fumadocs, Docusaurus, Starlight, Nextra या कोई अन्य फ़्रेमवर्क। यह पंक्ति-दर-पंक्ति पोर्ट के बजाय Blume की स्वाभाविक शैली को लक्ष्य करता है, और इसमें प्रत्येक नामित फ़्रेमवर्क के लिए एक मैपिंग संदर्भ, स्थानांतरित होने वाले हर URL के लिए एक रीडायरेक्ट, तथा जो कुछ भी यह छोड़ देता है उसकी एक रिपोर्ट शामिल होती है। इसे चलाने का सबसे तेज़ तरीका [`blume migrate`](/docs/migrating) है, जो आपके फ़्रेमवर्क का पता लगाता है और पैकेज में बंडल की गई प्रति पर Codex या Claude Code खोलता है। इसे किसी अन्य एजेंट से उपयोग करने के लिए, इसे इंस्टॉल करें:

```bash
npx skills add haydenbleasel/blume --skill blume-migrate
```

## स्वयं-अपडेट होने वाले डॉक्स [#self-updating-docs]

`blume-update-docs` आपके डॉक्स को उस प्रोडक्ट के साथ सिंक में रखता है जिसका वे दस्तावेज़ीकरण करते हैं। हर रन पर — आमतौर पर आपके एजेंट रनर में कॉन्फ़िगर किए गए शेड्यूल से — यह हाल ही में मर्ज हुए PR, चेंजलॉग, कॉन्फ़िग स्कीमा और CLI हेल्प का डॉक्स कंटेंट के साथ ऑडिट करता है, केवल उन्हीं पेजों को अपडेट करता है जो तथ्यात्मक रूप से पुराने पड़ चुके हैं (फ़ीचर-फ़्लैग किए गए काम को नज़रअंदाज़ किया जाता है), `blume build` और `blume validate` से सत्यापित करता है, और एक `blume/*` पुल रिक्वेस्ट खोलता या अपडेट करता है। अगर कुछ भी बदला नहीं है, तो यह शोरगुल वाला PR खोलने के बजाय एक साफ़ नो-ऑप रिपोर्ट करता है।

```bash
npx skills add haydenbleasel/blume --skill blume-update-docs
```

Blume इस ऑटोमेशन को होस्ट नहीं करता — इस स्किल को Claude Code में किसी शेड्यूल्ड टास्क, Codex या Cursor ऑटोमेशन, या साधारण cron से जोड़ें, और उसे रिपॉज़िटरी इतिहास पढ़ने तथा PR खोलने की अनुमति दें। एक सामान्य साप्ताहिक प्रॉम्प्ट:

```text
Use the blume-update-docs skill. Review the PRs merged within the last 7 days and compare them to the docs content. Ignore work behind feature flags. If docs need updates, make them, verify the docs build, and open a blume/* PR. If not, report what you checked and do not open a PR.
```

## अपनी साइट की स्किल लिखना [#writing-your-sites-skill]

`blume-write-skill` [आपके अपने डॉक्स के लिए एजेंट स्किल](/docs/discoverability/agent-discovery#your-sites-skill) लिखता है: डॉक्स पर आधारित एक `SKILL.md`, जो किसी कोडिंग एजेंट को आपके प्रोडक्ट का उपयोग करना सिखाती है — सेटअप, मूल अवधारणाएँ, सामान्य कार्य और ध्यान रखने योग्य बारीकियाँ — जिसमें प्रत्येक विषय उसके पेज से लिंक होता है। यह उस पेज मैप का स्थान लेता है जिसे Blume `/skill.md` पर जनरेट करता है। इसे चलाने का सबसे तेज़ तरीका `blume skill` है, जो यह तय करता है कि स्किल कहाँ रखी जानी चाहिए और पैकेज में बंडल की गई प्रति पर Codex या Claude Code खोलता है:

```bash
blume skill --claude   # or --codex
```

इसे किसी अन्य एजेंट से उपयोग करने के लिए, इसे इंस्टॉल करें:

```bash
npx skills add haydenbleasel/blume --skill blume-write-skill
```
