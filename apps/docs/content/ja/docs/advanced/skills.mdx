Blume は[エージェントスキル](https://docs.claude.com/en/docs/claude-code/skills)を提供しています。これは、コーディングエージェント（Claude Code、Codex、Cursor）に対して、あなたが説明しなくても Blume 特有の作業のやり方を教えるプレイブックです。スキルは GitHub 上のリポジトリの `skills/` フォルダーに置かれ、インストール済みパッケージにも `skills/` 配下にバンドルされているため、どのエージェントにも `SKILL.md` を直接指定できます。

## Blume

中核となるスキルです。Blume とは何か、そしてサイトをどのようにスキャフォールド・執筆・設定するか（ファイルシステムから導出されるナビゲーション、設定スキーマ、コンテンツコンポーネント）をエージェントに教え、インストール済みパッケージにバンドルされた完全なドキュメント（`blume` 内の `docs/` ディレクトリ。パッケージマネージャーがインストールした場所から解決されます。pnpm モノレポではリポジトリのルートではなく、依存しているワークスペースの `node_modules` です）へ誘導します。エージェントがドキュメント構築を手伝うプロジェクトにインストールしてください。

```bash
npx skills add haydenbleasel/blume
```

## 移行 [#migration]

`blume-migrate` は、既存のドキュメントサイトを Blume に移行します。対象は Mintlify、Fumadocs、Docusaurus、Starlight、Nextra、その他あらゆるフレームワークです。1 行ずつの移植ではなく Blume らしい構成を目指しており、上記の各フレームワーク向けのマッピングリファレンスを備え、移動するすべての URL にリダイレクトを設定し、移行しなかった内容をすべてレポートします。最も手軽な実行方法は [`blume migrate`](/docs/migrating) です。フレームワークを検出し、パッケージにバンドルされたスキルを使って Codex または Claude Code を起動します。他のエージェントから使うには、インストールしてください。

```bash
npx skills add haydenbleasel/blume --skill blume-migrate
```

## 自己更新するドキュメント [#self-updating-docs]

`blume-update-docs` は、ドキュメントを、それが説明している製品と同期した状態に保ちます。実行のたびに（通常はエージェントランナーで設定したスケジュールから）、最近マージされた PR、変更履歴、設定スキーマ、CLI ヘルプをドキュメントの内容と照合し、事実として古くなったページのみを更新し（フィーチャーフラグ配下の作業は無視されます）、`blume build` と `blume validate` で検証したうえで、`blume/*` プルリクエストを作成または更新します。ずれが何もなければ、無用な PR を作成せず、変更なしとして報告します。

```bash
npx skills add haydenbleasel/blume --skill blume-update-docs
```

Blume は自動化をホストしません。リポジトリ履歴の読み取りと PR 作成の権限を与えたうえで、Claude Code のスケジュールタスク、Codex や Cursor の自動化、あるいは単純な cron にスキルを組み込んでください。週次プロンプトの例:

```text
Use the blume-update-docs skill. Review the PRs merged within the last 7 days and compare them to the docs content. Ignore work behind feature flags. If docs need updates, make them, verify the docs build, and open a blume/* PR. If not, report what you checked and do not open a PR.
```

## サイト独自のスキルの作成 [#writing-your-sites-skill]

`blume-write-skill` は、[あなた自身のドキュメント向けのエージェントスキル](/docs/discoverability/agent-discovery#your-sites-skill)を作成します。これはドキュメントに基づいた 1 つの `SKILL.md` で、コーディングエージェントに製品の使い方（セットアップ、中核となる概念、よくあるタスク、注意点）を教えます。各トピックには対応するページへのリンクが付きます。このスキルは、Blume が `/skill.md` に生成するページマップの代わりになります。最も手軽な実行方法は `blume skill` です。スキルの配置場所を判断し、パッケージにバンドルされたスキルを使って Codex または Claude Code を起動します。

```bash
blume skill --claude   # or --codex
```

他のエージェントから使うには、インストールしてください。

```bash
npx skills add haydenbleasel/blume --skill blume-write-skill
```
