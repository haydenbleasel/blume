Blume は目次の下にある[ページアクション](/docs/content/navigation#page-actions)に **エクスポート** アクションを追加でき、読者が閲覧中のページを **PDF** または **EPUB** として保存できるようになります。デフォルトでは無効で、完全にクライアントサイドで動作します。サーバーは不要で、[静的](/docs/deployment)ビルドは静的なままです。

## 有効化する

ひとつのトグルで両方の形式を有効にできます。

```ts blume.config.ts
export: true,
```

片方の形式だけを提供したい場合は、代わりにオブジェクトを渡します。

```ts blume.config.ts
export: {
  pdf: true,
  epub: false,
},
```

省略した形式（または `false` に設定した形式）はメニューから除外されます。両方を無効にした場合（デフォルト）、**エクスポート** アクション自体が表示されません。

## PDF

**PDF にエクスポート** は、ヘッダー・サイドバー・ナビゲーションといったサイトのクロームを取り除いて記事本文だけにする印刷用スタイルシートを適用した状態で、ブラウザの印刷ダイアログを開きます。**PDF として保存** を選ぶと完了です。

実際にスタイルが適用されたライブページを印刷するため、結果として鮮明で選択可能なテキスト、本物のフォント、シンタックスハイライトされたコードがそのまま保たれます。依存関係は不要で、開発環境でも本番環境でも静的ホスティングでも同じように動作します。

:::note
PDF エクスポートはブラウザのネイティブな印刷ダイアログを経由するため、「PDF として保存」の正確な文言やオプションはブラウザによって異なります。コードブロックやコールアウトの背景を保持するには、ダイアログで **背景のグラフィック** を有効にしてください。
:::

## EPUB

**EPUB にエクスポート** は、現在のページの自己完結型 `.epub` をブラウザ内で生成してダウンロードします。Apple Books、Calibre、その他あらゆる電子書籍リーダーですぐに読めます。ジェネレーターは読者がエクスポートをクリックしたときにのみ読み込まれるため、サイトの他の部分に負荷をかけることはありません。

スタイルシートや JavaScript を持たないデバイス上でも読みやすいファイルにするため、Blume はページをクリーンで独立した HTML に書き換えます。シンタックスハイライトされたコードはプレーンな等幅テキストになり、装飾用のアイコンやコピーボタンは削除され、組み込みの電子書籍リーダー用スタイルシートが余白・コードブロック・テーブルを処理します。

## エクスポートされる範囲

どちらの形式も、読者が閲覧している **単一のページ** をエクスポートします。サイト全体ではありません。これは、アクションが配置されている場所、つまりそのページの目次の下という位置づけと一致しています。

:::note
EPUB にはタブを切り替えるための JavaScript がないため、[package-install](/docs/content/syntax) ブロックやコードグループなどのタブ付きコンテンツは、すべてのパネルが同時に表示されるように展開されます。Mermaid ダイアグラムのようなクライアントサイドでレンダリングされる埋め込みは含まれません。
:::
